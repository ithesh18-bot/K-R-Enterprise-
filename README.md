# K.R. Enterprises Billing System
Mobile-friendly single-page billing app for K.R. Enterprises.

## How to use on a phone
Open `index.html` in a browser or upload the project to a simple static host/editor.
- Add trip rows.
- Amount is automatically Trips × Rate.
- Save bills in the browser on that device.
- Use Print / Save PDF to create a printable bill.
- Share the bill summary using the phone share menu where supported.

No server or database is required for this first version.
